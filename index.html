Why COPE

Built for the work.
Not the hype.

01

Nothing is published automatically

You stay in control. COPE creates files, validates them, and leaves the final decision with you.

02

Use your preferred model

Configure Claude Code, Codex, Anthropic, OpenAI, or an OpenAI-compatible endpoint.

03

Fast, local visuals

Render information cards locally without image-generation or vision calls. Optional generated artwork is available.

04

Review is part of the product

Every run is isolated, every output is inspectable, and failures are explicit rather than silently reused.

Start with one command

Turn your next idea
into content.

Clone the repository, install the dependencies, and run COPE against any source you trust.

terminal
$ git clone https://github.com/sirius93/cope.git
$ cd cope
$ corepack enable
$ pnpm install --frozen-lockfile
$ pnpm cope run examples/post.md --all
